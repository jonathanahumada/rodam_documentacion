###################
Guía de usuario 
###################

Estos documentos conforman un conjunto de *documentación funcional*
dirigida a los usuarios finales de la aplicación.

Dado al marco ágil utilizado en el proyecto, no se encontrará documentación
para toda la funcionalidad del WebLab. Aquí solo se encontrarán documentadas
funcionalidades que en su momento se consideraron críticas para documentar.

Sin embargo, esta no es toda la documentación funcional
existente. Para un recurso más completo de documentación funcional se
deben consultar el *repositorio de videos* del WebLab, al cual
se puede acceder con las credenciales suficientes.
